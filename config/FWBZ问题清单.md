# FWBZ 数据库可回答的问题清单

> 用途:本文件**只包含问题**,不附带答案与 SQL 范式,用于喂给大模型当作 prompt 输入,
>     让大模型自己生成查询 SQL,节省它读完整手册的上下文与算力。
> 适用:`FWBZ` schema(达梦 8.0),详见 `FWBZ_strut.sql` 与 `FWBZ问答手册.md`。
> 共覆盖 17 个业务域 + 1 个跨域综合域,涵盖 113 张表的高频查询。

## 1. AI 报告与运行日志

1. 最近一周系统生成了哪些 AI 报告？
2. 某设备最近一次"故障分析报告"是什么内容？
3. 谁在什么时候调用了哪个接口、耗时多少？
4. 最近 24 小时的登录日志有多少条？是否异常？
5. 指定租户（多租户）最近一周的操作日志

## 2. 报警与告警

1. 当前还有多少未处理的告警？分布在哪些级别？
2. 某设备最近 N 天的告警频次是多少？
3. 哪些告警规则从来没有触发过（疑似"死规则"）？
4. 某空间告警的 TOP 10 类型分布
5. 某告警事件的完整处置过程（转工单 → 完成）
6. 哪些消防设备最近 24h 离线？

## 3. 设备与采集(核心台账 + 时序数据)

1. 某空间下挂着哪些设备/仪表？数量分别是多少？
2. 某设备的实时点位数据是多少？
3. 某设备最近 24 小时的能耗曲线（小时粒度）
4. 某设备本月的日能耗趋势
5. 某点位（属性）近 N 天的历史值
6. 哪些设备最后采集时间超过 X 小时没回数据（疑似离线）？
7. 某网关下挂了哪些设备？协议是什么？
8. 某设备最近一次数据修正前后的值

## 4. 空间位置

1. 空间树长什么样？
2. 某空间下子空间列表
3. 某空间下挂着多少设备/计量点？

## 5. 能源与计量

2. 某计量点本月日能耗与日费用
3. 某能源本月成本（按所选计费配置）
4. 各能介的折标煤系数 / 碳排放因子是多少？
5. 某能介当前生效的计费配置是什么？
6. 某能效分析方案包含哪些图表/基准？
7. 某计量点下挂的设备清单

## 6. 照明

## 7. 联动与场景

## 18. 跨域综合问题(精选)

- X1. 某场馆的"一次活动"综合报告:活动信息 + 总结报告 + 客流 + 能耗
- X2. 某空间"设备健康度"画像:设备总数 / 运行数 / 离线数 / 告警数 / 消防告警数
- X3. 某能介本月"能碳看板":能耗 + 折标煤 + 碳排 + 成本
- X4. 设备"告警 → 工单 → 完成"全链路追踪:alarm_record + log_point_execute_record
- X5. 某空间当天告警 / 客流 / 能耗 / 设备状态一站式速览
- X6. 某设备最近一次 AI 故障分析报告及同期告警对照
- X7. 联动策略某次执行涉及的"前置点位 + 后置点位 + 触发值 + 结果"
- X8. 某活动能耗 vs 同类活动能耗对比(单人次能耗 / 总用电 / 客单耗)
- X9. 某空间"未处理"告警、设备离线、消防告警综合清单
- X10. 某月份各能介能耗 Top10 计量点及对应计费配置

---

**总问题数**:86

**使用建议**:
1. 把整篇内容作为 system prompt 或 user prompt 喂给大模型
2. 让大模型只输出 SQL(达梦 8.0 语法),不要重新解释问题
3. 若大模型答不出,回查 `FWBZ问答手册.md` 对应章节号获取 SQL 范式
4. 提问时附上"业务域编号 + 问题编号",如 `2.3 表示第2章第3问`
