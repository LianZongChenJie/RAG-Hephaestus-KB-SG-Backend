# FWBZ 数据库可回答的问题分类速查

> **用途**:按"业务主题"重新组织 FWBZ 数据库可回答的问题,便于业务人员按场景提问。
> **Schema**:`FWBZ`(达梦 8.0)。
> **配套文档**:`FWBZ问答手册.md`(带 SQL 范式)、`FWBZ问题清单.md`(只列问题,供大模型 prompt)。
> **数据来源**:`FWBZ_strut.sql`(113 张业务表)。

---

## 快速选择

- 看"今日/当前/近 N 小时"统计 → 第 1、2、5、6、8、9 章
- 看台账 / 状态 / 离线 → 第 3、4、7 章
- 看接口 / 系统 → 第 10 章

---

## 一、能耗与计费(最常用)

1. 今日总能耗是多少?
2. 今日各能介(电/水/气/热)能耗分别是多少?
3. 今日各空间 / 场馆能耗排名?
4. 今日能耗费用 / 成本是多少?
5. 本月累计能耗是多少?
6. 今日峰 / 平 / 谷 / 尖分时电量各多少?
7. 某设备最近 24 小时能耗曲线?
8. 今日折标煤 / 碳排放是多少?
9. 当前某设备的实时功率是多少?
10. 某能介当前生效的计费配置是什么?
11. 某能介本月成本(按所选计费配置)?
12. 各能介的折标煤系数 / 碳排放因子是多少?
13. 某计量点下挂的设备清单?
14. 某计量点本月日能耗与日费用?
15. 某设备的倍率 / 单位是什么?

---

## 二、报警与异常

1. 当前还有多少未处理的告警?分布在哪些级别?
2. 今日发生多少条告警?
3. 各级别 / 各类别告警分布?
4. 某设备最近 N 天的告警频次?
5. 某空间告警 TOP 10 类型分布?
6. 哪些告警规则从来没有触发过(疑似"死规则")?
7. 哪些消防设备最近 24h 离线?
8. 紧急未处理消防报警清单?
9. 今日告警转工单数 / 完成数?
10. 某告警事件的完整处置过程(转工单 → 完成)?

---

## 三、设备与采集

1. 某空间下挂着哪些设备 / 仪表?数量分别是多少?
2. 当前离线设备清单(>N 小时无心跳)?
3. 各设备类别数量分布(仪表 vs 设备)?
4. 设备运行状态分布(运行 / 停止 / 故障)?
5. 某设备的实时点位数据是多少?
6. 某设备本月的日能耗趋势?
7. 某点位(属性)近 N 天的历史值?
8. 某网关下挂了哪些设备?协议是什么?
9. 某设备最近一次数据修正前后的值?
10. 各空间设备数量对比?
11. 某型号 / 类别的设备清单?
12. 设备类别树结构?

---

## 四、视频监控

1. 离线摄像头清单?
2. 各分组摄像头数量?
3. 某区域(含子区域)下所有摄像头?
4. 某经纬度附近 N 米的摄像头?
5. 某巡更计划调用的摄像头清单?
6. 今日事件订阅通知数 / 分类?
7. 某摄像头最近一次在线 / 离线时间?
8. 海康 / 萤石平台同步监控点数量?
9. 区域树(海康 / 萤石)长什么样?

---

## 五、门禁 / 人员识别 / 客流

1. 门禁设备在线 / 离线清单?
2. 某门禁点最近 N 条刷卡记录?
3. 某门今天的进出次数?
4. 今日各场馆客流峰值对比?
5. 某场馆 24 小时分时客流曲线?
6. 今日识别记录数 / 异常行为数?
7. 某人员最近 N 天的识别记录?
8. 每日人员统计(进场 / 在场 / 异常)?
9. 门禁点当前开关状态?
10. 近 30 天访客统计趋势?

---

## 六、停车场

1. 今日停车统计(进场 / 在场 / 剩余 / 平均时长)?
2. 某车牌最近 N 条停车记录?
3. 哪些车辆在停车场停放超过 N 小时?
4. 各停车场今日流量排名?
5. 今日各方向(入口 / 出口)流量?
6. 某停车场当前剩余车位数?

---

## 七、照明与联动

1. 当前哪些回路处于开启状态?开启时长?
2. 某区域的照明计划执行表?
3. 某回路最近 N 条操作记录?
4. 各照明计划今日执行了几次?
5. 当前启用了哪些联动策略?
6. 联动策略今日触发次数与成功率?
7. 哪些联动策略最近 24h 失败?
8. 某空间下的所有场景化策略?
9. 某策略执行时间表(工作日 / 时段)?
10. 某次联动执行的点位级执行明细?

---

## 八、消防

1. 哪些消防设备电量低?
2. 哪些设备最近 N 天没回心跳(最后巡检时间过老)?
3. 紧急(level=4)未处理消防报警?
4. 各类型消防设备数量(烟感 / 温感 / 光感 / 消防栓)?
5. 今日消防报警趋势?
6. 某消防报警的处理过程?

---

## 九、投诉 / 活动

1. 今日各类型投诉数量?
2. 当前待处理投诉清单?
3. 投诉状态分布(待处理 / 处理中 / 已处理)?
4. 近 30 天投诉量趋势?
5. 各处理人处理量排名?
6. 某投诉完整处理过程?
7. 当前进行中的活动?
8. 某活动筹备完成度?
9. 已总结活动报告清单?
10. 某活动总用电量 / 单人次能耗?

---

## 十、运维 / 系统

1. 今日系统生成了哪些 AI 报告?
2. 某设备最近一次"故障分析报告"是什么内容?
3. 谁在什么时候调用了哪个接口、耗时多少?
4. 最近 24 小时的登录日志有多少条?是否异常?
5. 指定租户(多租户)最近一周的操作日志?
6. 慢接口 TOP N?
7. 哪些接口最近 5 分钟没心跳?
8. 接口平均响应时间 / 调用量 TOP 10?
9. 某角色被授权了哪些资源?
10. 某业务配置项的当前值是什么?
11. 今日 MQTT 低压配电遥测接收量?
12. 某冷源 tag 最近 N 个遥测值?
